# my-book-store-app

A full-stack online book store application developed as a team project.

## Team Structure
- Frontend (User): User-facing website
- Frontend (Admin): Admin dashboard
- Backend: APIs, authentication, database

## Branch Strategy
- main: Production-ready code
- develop: Integration branch
- frontend-user: User-side frontend development
- frontend-admin: Admin-side frontend development
- backend: Backend development

## Tech Stack (Planned)
- Frontend: React (Vite)
- Backend: Node.js / Spring Boot
- Database: TBD
- Authentication: TBD
